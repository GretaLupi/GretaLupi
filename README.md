# Greta Lupi

Physicist at Aalto University, Helsinki. I build machine-learning methods that infer the Hamiltonians of quantum
materials and molecules from experimental scanning tunnelling spectroscopy, and I test them on real data with
experimental groups at Aalto and Empa.

## What I work on

- **Hamiltonian learning:** estimating the parameters of quantum spin models from measured spectra, and checking how
  far the estimates can be trusted under noise and imperfect models
- **Generative inference:** diffusion models that combine simulated and experimental data and return ensembles of
  compatible models instead of a single fit
- **Simulation:** quantum spin systems with tensor networks (DMRG); background in DFT and many-body methods
- **Tools for experimentalists:** analysis pipelines with a browser interface that work without writing code

| Project | What it is |
